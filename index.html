QwensWorld

A personal desktop tool for one production designer's workflow.

QwensWorld runs on a single Windows computer. It reads its owner's own work email locally to notice requests for book files, and keeps a list of those requests.

It signs in to Google only to add and update items in its owner's own Google Tasks list, so each request shows up as a to-do. It does not read, change, or share any other Google data, and it is not offered to other people.
