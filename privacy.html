QwensWorld privacy policy

Last updated November 24, 2026

QwensWorld is a personal tool used by its developer only. It is not offered to the public.

Google data it uses

QwensWorld asks for one Google permission: access to Google Tasks (https://www.googleapis.com/auth/tasks). It uses it only to find or create one task list and to add or update tasks in it for its owner. It does not use any other Google data.

Where data is kept

The Google sign-in token and the list of tasks are stored only on the owner's own computer. Nothing is sent to any server run by QwensWorld; there is none.

Sharing

QwensWorld does not sell, share, or transfer Google user data to anyone, and does not use it for advertising or to train AI models.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the app's data folder on the computer removes everything it stored.

Contact

Questions go to the developer contact email shown on Google's sign-in screen for this app.
